## Text size roles (one scale, both windows)
Defined once in `ui/src/tokens.css` as `--fs-*`; `styles.css` (popover) and `editor.css` (Tailwind `@theme`, utilities `text-display|title|body|small|label`; Tailwind's default `text-xs/sm/lg...` are removed) read them. Never write a pixel size or a raw `text-xs|sm|base|lg|xl` / `text-[Npx]`: `src/type-scale.test.ts` fails on it.
- `--fs-display` 26 px: the big BPM only.
- `--fs-title` 15 px semibold (`.t-head`): track, section, card and guide headers, palette role names.
- `--fs-body` 13 px (the default on `body`): body text, buttons, chips, list items, clip names, status texts, segmented controls, steppers, inputs and selects.
- `--fs-small` 12 px (`text-small`): secondary or dim text, hints, descriptions, lengths ("2 bars", "auto"), footer.
- `--fs-label` 11 px (`.t-label`, uppercase, tracked, dim): field labels.
Names inside a header's content (clips, sequences) are body, so they are always smaller than the track header.

## Editor visual language (redesign spec 4)
- Top bar, always the same: tabs (Sets, Sequences, Palettes, Strip, Detection, Setup, each with a line icon), undo, redo, separator, duplicate, delete (red; only where something is selected), save state, help (?), live readout.
- Save state: "Saving…", "✓ Saved", red "Not saved — <reason>". Live readout: "● 122.0 BPM · beat 2 · phrase: bar 3 of 8 · <icon> Rhythm" or "○ No clock". Delete asks: `Delete "<name>"? You can undo this with ⌘Z.` (Cancel / Delete).
- Label left of its field, same row. Left navigator (search, list) in Sets, Sequences, Palettes.
- One teal accent (`--color-accent`) for live, selection and valid drop targets; red only for delete and errors; no colour per moment. Moment icons: Rhythm pulse, Calm wave, Build-up rising arrow.
- Icons: bundled line SVGs (Lucide, ISC, see `ui/src/icons/LICENSE.md`); no emoji or pictographs anywhere. Undo/redo are disabled on Strip and Detection with the hint "This tab applies changes at once, so there is nothing to undo.", and on Setup with "Settings apply at once; use Reset to defaults instead."
